# Catchphrase

Catchphrase builds a personalized phrasebook for an upcoming real-world conversation: a short guided setup, then things to say, likely exchanges, words and an example conversation in the learner's target language.

| Path | Contents |
|---|---|
| `web/app/` | Mobile-first TypeScript PWA |
| `api/` | Stateless Cloud Run API and gateway configuration |
| `ios/` | Native iOS client |
| `evals/` | Offline content-quality evaluation tooling |
| `explorations/` | Self-contained HTML interface studies |
| `scripts/` | Repository tools (`check-docs.mjs`, `tmux-server.sh`, worktree setup) |
| `docs/` | The project wiki |
