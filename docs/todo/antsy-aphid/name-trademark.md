# Product name and trademark check

Part of [Launch: Antsy Aphid](../antsy-aphid.md).

- **What:** check that the public name can be used (trademark search in launch markets, App Store and domain availability), pick the final name, and align the web manifest, iOS app and store listing on it.
- **Why:** owner accepted the suggestion, 2026-11-12. The product is Catchphrase in the wiki and the web manifest (`web/app/vite.config.js`), Catchphrase is also the name of a long-running TV game show, and the iOS app is still named Loudmouth (`ios/Loudmouth.xcodeproj/project.pbxproj`, bundle identifier `com.fightinjoe.Loudmouth`). A rename after a store listing is costly.
- **Done when:** the chosen name is recorded in [decisions](../../decisions.md) with the checks behind it, and the web manifest, iOS display name and store listing use it.
