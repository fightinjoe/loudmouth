# Route English generation by provider performance

Part of [Launch: Antsy Aphid](../antsy-aphid.md).

- **What:** replace the Relace-only pin in `callDeepSeek` (`api/src/llms/openrouter.js`) with OpenRouter's performance-based routing: no `only` list, `allow_fallbacks: true`, `require_parameters: true` (kept, so only providers that support the [JSON schema](valid-json.md) are used), `preferred_min_throughput: {p90: 150}`, `data_collection: 'deny'`, and `ignore: ['wafer', 'novita', 'open-inference']` for providers that kept failing validation or quality in the 2026-11-13 live samples. Every provider attempt logs an `llm_call` event (provider, duration, output tokens, tokens per second, attempt, outcome, `topicIndex`, `requestId`). `DEEPSEEK_TIMEOUT_MS` (120 s) stays as it is, a last-resort cap. Target: under 10 s per topic (3 s ideal, 6 s acceptable). Tracking (owner approval 2026-11-13): every API route writes structured logs as single-line JSON so Cloud Logging can query them, and `scripts/generation-report.mjs` summarizes them for a time window.
- **Why (logging):** before this change the API logged objects with `console.log({...})`, which Node prints over several lines, and Cloud Run stored each line as a separate text entry (production read 2026-11-13), so no event could be filtered or counted. Production logs are kept for 30 days.
- **Local result (2026-11-13):** 43 of 44 topics finished in under 10 s, with p50 4.5 s, across 14 providers ([live samples](../../evals/results/2026-11-13-generation-reliability-local.md)). OpenInference was ignored after that run because its replies wrote the English source in Spanish and produced exchanges of up to 35 turns. Neither problem is caught by validation, so new providers can still bring the same risk. Watch the per-provider table in the report.
- **Why:** per-topic latency on the pinned provider rose from 2.2–4.0 s (2026-11-02) to as much as 39.4 s (2026-11-11). Time to first token stayed normal while output speed fell from 195–294 to 18 tokens/s, and other providers were faster in the same window ([evaluation record](../../evals/results/2026-11-12-english-prompt-candidate-4.md#latency)). Owner decisions 2026-11-13: rely on OpenRouter for probing, routing and timeouts instead of our own probes or provider list. OpenRouter re-ranks providers on 5-minute throughput and latency percentiles and retries timed-out or failed requests on another provider; a slow but still-streaming provider is only avoided for later requests, hence the 120 s cap. The threshold is an estimate: at the healthy speeds above, a topic is roughly 400–1,200 output tokens, and 1,200 tokens in under 10 s needs about 135 tokens/s. Check it against the logged output tokens. `deny` keeps users' seed text away from providers that may store it; widen it only if performance requires. A topic whose DeepSeek call still returns 429 moves to Gemini 3.5 Flash Lite (adopted 2026-11-14, superseding the 2026-11-13 no-fallback decision; [decisions](../../decisions.md)). Load tests and capacity planning are deferred to [DeepSeek load testing](../backlog/deepseek-load-testing.md).
- **Done when:** the routing settings and per-call logging are deployed, and [POST /phrasebook](../../api/phrasebook.md) (`english.call`) and [API operations](../../api/operations.md) describe them; [production verification](production-verification.md) measures the target.
