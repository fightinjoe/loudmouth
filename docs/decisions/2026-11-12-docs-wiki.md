# Documentation as a wiki

## Context

A November 2026 audit of the repository's documentation found that the endpoint and schema specs matched the code, but that the surrounding material had decayed:

- Status facts were copied into many pages. "v4 is not deployed; native iOS is unchanged" appeared in nine documents, and model defaults in six. Every contradiction found was a copy that missed an update, for example web architecture still naming the v3 database.
- About ten documents and six agent commands described the removed `/lookup` and `/textbook` era while still looking authoritative. Nested agent files gave rules that contradicted the code.
- Test-run diaries and migration notes sat inside specs and READMEs; decisions were scattered across the rubric, the to-do list, design documents and files outside the repository.
- Nothing checked links or paths, and CI ignored documentation changes.

## Decisions

- One wiki under `docs/`, after the [LLM wiki pattern](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): sources (code) → wiki pages → schema (`AGENTS.md` and [`wiki.md`](../wiki.md)).
- Pages describe the current state. Planned work goes in `todo/`, future designs in `proposals/`.
- Todos, decisions, evaluation results and exploration status are ledgers: one dated line each, with optional detail records. This replaces separate decision and evidence documents, which the owner judged likely to become long, hard to read and short of context.
- Every page carries a header block (`kind`, `status`, `summary`, `sources`, `verified`), so the index can be generated and stale pages detected.
- `scripts/check-docs.mjs` enforces the conventions in CI and in the commit and finalize worktree skills. Repeatable jobs get scripts rather than agent judgment.
- Skills are thin shells pointing to `docs/skills/`, so the owner can review and edit them in the wiki. Unreviewed skills are disabled; new skills are prefixed `ajw_`.
- No shared append-only log: parallel worktrees would conflict on it. Each worktree keeps a gitignored `worktree.md` with its intent and changelog.
